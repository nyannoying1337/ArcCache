# Interface wording

Primary screens describe the action and what to do next. Technical information stays in expandable support/game-check details and troubleshooting logs.

| Previous wording | Current wording |
| --- | --- |
| Driver experiments / isolated device probe | Try a compatibility check / Run the graphics check |
| Prepare original control / private driver set | Set up this game / first setup |
| Use system driver again | Use default settings |
| DevOverride/private-driver routing | Enable game-specific settings, with a restart explanation |
| Recovery receipt / pinned profile / constructor signature | Saved setup record / game found / support details |

Cache-size units remain MiB/GiB so sizes are accurate. Graphics checks do not claim gameplay support or measured cache capacity. Multiplayer/account warnings, closed-game checks, manual administrator-only Windows setting changes and explicit consent remain intact.
