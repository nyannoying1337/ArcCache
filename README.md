# Historical experimental edition

The experimental features have been merged into the [unified Arc Cache preview on main](https://github.com/nyannoying1337/ArcCache). New builds use one executable, `ArcCache.exe`, including the reviewed 8/16 GiB options with their existing experimental/RAM warnings and driver restrictions.

[Download the unified preview](https://github.com/nyannoying1337/ArcCache/releases/tag/arc-cache-unified-libraries-preview-2026.10.15) · [Current documentation](https://github.com/nyannoying1337/ArcCache/tree/main/docs) · [Current source](https://github.com/nyannoying1337/ArcCache/tree/main/src)

This branch retains the older experimental source for release reproducibility and recovery. Earlier release assets are retained; they are not the current download. Existing receipts/settings are shared with the unified app, and normal compatibility/recovery checks still apply. Do not run older and newer instances together when changing a setup.
